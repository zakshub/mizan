# 03. Agents and Expert Packs

## Agent roles
- Thesis: strongest case in favour.
- Antithesis: strongest case against.
- Evidence: shared claim ledger and verification status.
- Judge: structured verdict and confidence-calibrated decision.

## Structured contracts
- Agent output must include message type, claims, evidence links, and decision impact.
- Judge output must include verdict, headline, confidence, lean, arguments, verified facts, assumptions, risks, missing information, conditions, next action, and explanation.

## Expert Pack system
- Expert Packs are versioned configuration bundles, not model fine-tunes.
- They define prompts, criteria, safety constraints, terminology, and tool access.
- Domain readiness states include available, research required, general reasoning only, qualified expert required, and insufficient context.

## Career and Hiring pack
- Analyse recruiter messages, role fit, compensation, schedule, employment structure, growth, risk, and negotiation leverage.
- Never invent salary bands, market rates, or employer motives.
- Label facts as verified, user provided, inference, assumption, or unknown.
