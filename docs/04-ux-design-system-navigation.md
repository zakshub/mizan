# 04. UX, Design System, and Navigation

## Shell layout
- Top bar: current channel, debate, evidence, analytics, history, search, notifications, help, account.
- Left rail: workspace, channels, active agents, system status.
- Main channel: topic, live status, round timer, messages, user interventions, composer.
- Right rail: settings, summary, confidence, risks, missing info, next step.
- Bottom controls: pause, stop, export, voice, language, start debate.

## Navigation model
- Each decision topic is a channel.
- Commands include topic, rounds, pause, resume, stop, evidence, verdict, and language.

## Visual system
- Calm light theme with off-white surfaces, cool grey borders, dark navy text, and restrained semantic colours.
- Semantic tokens for thesis, antithesis, judge, evidence, and danger.
- Urdu requires full RTL layout support, not just right-aligned text.

## Accessibility
- WCAG 2.2 AA target.
- Visible focus states and accessible names.
- Live streaming announcements should be polite, not token-by-token noisy.
- Reduced-motion support is required.
